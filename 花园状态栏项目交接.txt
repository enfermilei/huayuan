1. 项目是什么
================================================================================

基于酒馆助手模板，给角色卡「在满是数删的神秘组织里当主人」做的 MVU 状态栏前端。

项              内容
--------------  --------------------------------------------------------------
本地仓库        e:\tavern_helper_template-main
业务代码        src/花园/
GitHub          https://github.com/enfermilei/huayuan（origin）
技术栈          Vue 3 + Pinia + Zod 4 + Tailwind(可用) + 酒馆助手 API + MVU
运行形态        消息楼层 iframe 前端（禁止核心逻辑回退到正则 inline <script>）
设定方向        花园组织经营 / 成员管理 / 赌场·酒馆 / 庄园地图等
展示内容        世界氛围条、主角、组织、在场成员(立绘)、名册、地图、背包、设置


================================================================================
2. 关键背景（为何是 iframe）
================================================================================

旧方案：整份 HTML（含 <script>）进酒馆正则。
根因：SillyTavern innerHTML 注入时 <script> 不执行 → 界面停在 -- / 同步中...
验证：DOM 有 init 源码字符串，但 typeof init === 'undefined'。

现方案：酒馆助手 iframe；视觉在 CSS/Vue，逻辑在 TS。
正则只做占位 → $('body').load(状态栏 URL)。

5. Schema 摘要
================================================================================

stat_data：
  系统      日期/时间/星期/天气/温度；组织全局；金缕赌场；迷迭香酒馆
            （UI 可读 系统.时段；无则用 时间推断氛围）
  成员名册  职务、位置、好感、忠诚、目标、身体、着装、怀孕、立绘、在场、背包…
  主角      职务、位置、贡献、资金、着装、背包

注意：
- 好感/忠诚：schema clamp -100~100；进度条 UI 用 abs → 0~100%
- 是否在场：z.boolean()；UI isPresent 兼容 'true'/1
- 立绘：日常|服装|性事 + 次类型校验 + 差分 1|2
- 背包：{ 描述, 数量 }；数量≤0 会被 transform 去掉

6. 立绘约定与资源清单
================================================================================

路径：
  portraits/{角色名}/{角色名}-{主类型}-{次类型}-{差分}.png
例：portraits/天音纯/天音纯-日常-普通-1.png

角色目录（各约 30 张 png，2026-08-09）：
  天音纯 / 天野神乐 / 夏语冰 / 神无咲 / 雪之下琴音 / 白石响子 / 莉莉露

resolvePortrait 优先级：
  1) 本机锁定（portraitLocks）
  2) 安全模式且 R18 → 日常-普通-1
  3) 自定义立绘 IndexedDB
  4) CDN DEFAULT_PORTRAIT_BASE/.../stem.png
  5) placehold

默认 CDN 基址（代码写死）：
  https://testingcf.jsdelivr.net/gh/enfermilei/huayuan@main/portraits

R18（安全模式隐藏）：主类型=性事；或 服装+裸体

锁定：localStorage garden-mvu:portrait-locks
  入口：身份卡「锁定/解锁立绘」；设置可批量清除
  注意：锁定后再套安全模式——锁定 R18 仍可能被安全模式盖成日常

在场卡：宽约 280px；立绘区 aspect-ratio 832/1216；object-fit:contain；
给 card-body 留高，避免裁切好感/忠诚栏。
